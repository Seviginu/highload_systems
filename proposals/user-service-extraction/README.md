# Архив предложения о выделении пользователей

Предложение применено после подтверждения продолжения пользователем.
Актуальные код, тесты и миграция находятся в tracker-service, пользовательский
CRUD и его тесты — в user-service. Gateway переключён на два бизнес-сервиса.

tracker-integration.patch и копии первоначальных файлов сохранены как архив
исходного предложения. Повторно применять patch не нужно; он не отражает
все последующие доработки тестов, Compose, Gateway и переноса данных.

Прежние сценарии пользовательского ControllerTest перенесены на WebTestClient,
ServiceImplTest — на реактивный UserServiceContractTest. UserMapperTest и
R2DBC UserIT проверяют маппинг, CRUD, уникальность email, валидацию, миграции,
пагинацию и OpenAPI. Запрет физического удаления используемого пользователя
заменён проверкой логического удаления и сохранения исторических ссылок.
Проверка роли тимлида перенесена в UserDirectoryTest и ProjectIT.

Миграция снимает только fk_tasks_author, fk_tasks_assignee,
fk_project_members_user; прежние changesets и данные users сохраняются.
Порядок переноса прежних ID описан в README корня репозитория.
