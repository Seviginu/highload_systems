# Подготовленное переключение трекера

Эта директория не входит в Maven-модули или Liquibase changelog. Patch сохранён
для продолжения работы; его сборка и межсервисные тесты ещё не проверены.
Не применять отдельно от адаптации тестов и переключения Gateway.

`tracker-integration.patch` содержит предложенные изменения:

- Feign Client с discovery по имени user-service и внутренней проверкой ID/ролей.
- Скаляры authorId, assigneeId и userId вместо JPA-связей с пользователями.
- Удалённая проверка до локальной транзакции; создание проекта и участника,
  изменение/перенос задачи остаются локальными транзакционными операциями.
- Отказ удалённого сервиса переводится в 503; Circuit Breaker добавляется позже.
- Новая миграция снимает fk_tasks_author, fk_tasks_assignee и
  fk_project_members_user. Между отдельными БД эти FK сохранить невозможно;
  проверка активных пользователей переходит в Feign. Старая таблица users
  сохраняется для последующего переноса данных с прежними ID.
- Внутри patch есть удаление старого пользовательского пакета и перенос
  UserMapperTest; текущий tracker-service сохраняет исходные файлы и все тесты.

Автоматическая проверка отклонила применение снятия FK и пакетную переработку
старых тестов без отдельного подтверждения. Рабочая БД не изменялась.
Для продолжения требуется подтверждение этих двух конкретных действий.
При адаптации тестов сохранить проверяемые сценарии: пользовательские перенести
в user-service с новым DELETE, трекерные перевести на HTTP-stub Feign; проверить
rollback, отсутствующего пользователя, неверную роль и недоступность сервиса.

До переключения следует определить запуск с новой БД либо перенос существующих
пользователей с сохранением ID, timestamps и корректной настройкой sequence.
Gateway, Compose и старые данные не переключаются этим patch автоматически.
